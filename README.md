# Hey there, I'm goofydash 👋

I build mobile apps that aim to feel less like software and more like something you'd actually want to open again. Most days I'm in Flutter and Dart, sometimes drifting into React Native, always chasing that moment when an animation just clicks. I keep coming back to offline-first design because I think the best apps shouldn't punish you for a bad signal.
